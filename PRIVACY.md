# Передача данных

SDK для работы обращается к серверам BAVInvest Ltd и передает:

* данные для проверки лицензии, включая идентификаторы лицензии и устройства;
* технические сведения о версии SDK;
* статистику использования SDK, включая сведения о подключениях и торговых операциях.

Данные используются для проверки лицензии и сбора статистики использования. Передача необходима для работы SDK и не отключается.

Вопросы по обработке данных: [support@in.fsr-develop.com](mailto:support@in.fsr-develop.com).
